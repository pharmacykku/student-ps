# ระบบฐานข้อมูลนักศึกษา ป.ตรี คณะเภสัชศาสตร์ มข. (GAS + Google Sheets + Google Drive)

## ไฟล์
- Code.gs      – ฝั่งเซิร์ฟเวอร์ (API, login, นำเข้า, Drive)
- Styles.html  – CSS กลาง (โหมดสว่าง/มืด)
- Index.html   – หน้าหลัก Dashboard (ผู้ใช้ทั่วไป, ไม่มีข้อมูลส่วนบุคคล)
- Admin.html   – หน้าผู้ดูแลระบบ (?page=admin)
- Export.html  – ระบบส่งออกกลาง CSV / Excel / PDF (ใช้ทั้ง 2 หน้า) ← ไฟล์ใหม่ สร้างเป็นไฟล์ HTML ชื่อ Export

## ติดตั้ง
1. สร้าง Google Sheet ใหม่ > ส่วนขยาย > Apps Script
2. สร้างไฟล์ตามชื่อด้านบน (Styles/Index/Admin เป็นไฟล์ HTML) แล้ววางโค้ด
3. เลือกฟังก์ชัน `setup` > Run > อนุญาตสิทธิ์
   - สร้างชีต: นักศึกษา, ผลการเรียน, ผู้ใช้, บันทึกการแก้ไข, ไฟล์, ตั้งค่า
   - สร้างโฟลเดอร์ Drive "ฐานข้อมูลนักศึกษา เภสัชฯ มข." (ไฟล์นักศึกษา / ไฟล์นำเข้า / สำรองข้อมูล)
   - บัญชี Google ที่รัน setup() จะเป็น "ผู้ดูแลหลัก" (owner) อัตโนมัติ → เข้าระบบด้วยอีเมลนั้น + OTP
4. Deploy > New deployment > Web app
   - Execute as: Me · Who has access: Anyone (หรือ Anyone within KKU)
5. เข้าหน้า Admin: <URL>?page=admin > แท็บ "นำเข้าข้อมูล" > ลากไฟล์ Excel รายชื่อ ปี 1–6 เข้าไป
6. นำเข้าผลการเรียน (GPA/GPAX รายภาค) ด้วยแม่แบบในแท็บเดียวกัน → กราฟ GPAX/แนวโน้มจะแสดงผล
7. เปิดสำรองอัตโนมัติรายวันได้ที่แท็บ ตั้งค่า (หรือรัน `installDailyBackup` จาก editor)

## อัปเดตเวอร์ชัน (ค้นหารายบุคคล + แนวโน้มรายคน)
1. วางทับไฟล์ทั้ง 4 ไฟล์
2. **รัน `setup()` อีกครั้ง 1 ครั้ง** เพื่อเพิ่มคอลัมน์ใหม่ในชีต "นักศึกษา": โรงเรียนเดิม, GPAX มัธยมปลาย, รอบการรับเข้า (ข้อมูลเดิมไม่หาย)
3. Deploy > Manage deployments > แก้ไข > New version
4. นำเข้าข้อมูลคอลัมน์ใหม่ได้ทางไฟล์ Excel (รหัสนักศึกษา + คอลัมน์ใหม่) ในแท็บนำเข้าข้อมูล
   - ชื่อคอลัมน์ที่รองรับ: โรงเรียน/โรงเรียนเดิม, GPAX ม.6/เกรดเฉลี่ย ม.ปลาย/GPAX มัธยมปลาย, รอบ/รอบการรับเข้า/TCAS
   - รอบการรับเข้าพิมพ์ 1/2/3/4, Portfolio, โควตา, Admission ได้ ระบบแปลงให้อัตโนมัติ
5. ลิงก์ตรงหน้าค้นหา: <URL>?page=admin&tab=search

## อัปเดตเวอร์ชัน (ไฟล์ตรวจสอบจบ + รายงานสิ้นภาค)
1. วางทับไฟล์ทั้ง 4 ไฟล์ → **รัน `setup()` อีกครั้ง** (สร้างชีต: รายวิชา, สรุปตรวจสอบจบ, อาจารย์ที่ปรึกษา, ประวัติส่งรายงาน)
2. ครั้งแรกที่ส่งอีเมล Google จะขอสิทธิ์ "ส่งอีเมลในนามคุณ" (MailApp) ให้กดอนุญาต แล้ว Deploy เป็น New version
3. ถ้าติดตั้งไว้ก่อนแล้ว เกณฑ์เฝ้าระวังยังเป็น 2.25 → เปลี่ยนเป็น 2.50 ที่แท็บ ตั้งค่า

### แท็บ 📄 ไฟล์ตรวจสอบจบ
- ลากไฟล์ PDF จาก REG (REG:F60-20-11) ได้หลายไฟล์พร้อมกัน หรือไฟล์เดียวที่รวมหลายคน (ระบบแยกหน้าตามรหัสให้)
- บันทึกแล้วระบบจะ: เขียนรายวิชาทุกครั้งที่ลง (ชีต รายวิชา) · คำนวณ GPA รายภาค/GPAX สะสม (ชีต ผลการเรียน) · สรุปสถานะหมวด/หน่วยกิตขาด/รอเกรด/ภาษาอังกฤษ (ชีต สรุปตรวจสอบจบ) · เก็บ PDF ใน Drive และอัปเดตลิงก์ใบตรวจสอบจบ
- GPAX สะสมคำนวณแบบ REG (ใช้เกรดครั้งล่าสุดของวิชาที่ลงซ้ำ) และภาคล่าสุดใช้ค่าทางการจากไฟล์
- อัปโหลดซ้ำ = แทนที่ข้อมูลเดิมของคนนั้น

### แท็บ 📨 รายงานสิ้นภาค
1. เลือกภาค → ระบบจัดกลุ่มนักศึกษา (กำลังศึกษา) GPAX < 2.00 และ 2.00–2.49 ตามอาจารย์ที่ปรึกษา
2. ครั้งแรก: กด "ดึงรายชื่ออาจารย์จากข้อมูลนักศึกษา" แล้วกรอกอีเมลอาจารย์ในตาราง → บันทึกอีเมล (ใช้ต่อได้ทุกภาค)
3. ดูตัวอย่างอีเมล → ติ๊กเลือก → ส่ง (ส่งทีละ 10 ท่าน, บันทึกประวัติในชีต ประวัติส่งรายงาน, กันส่งซ้ำโดยแสดงสถานะ "ส่งแล้ว")
4. ส่งออก Excel หรือบันทึก Google Sheet (โฟลเดอร์ รายงานสิ้นภาค/) เก็บเป็นหลักฐาน
5. ตั้งค่าอีเมล CC (เช่น อีเมลงานบริการการศึกษา) ได้ที่แท็บ ตั้งค่า
- โควตาส่งอีเมล: บัญชี Gmail ส่วนตัว 100 ฉบับ/วัน, Google Workspace 1,500 ฉบับ/วัน

## เข้าสู่ระบบด้วยอีเมล + OTP (เวอร์ชันล่าสุด)
- ไม่มีรหัสผ่านแล้ว: กรอกอีเมล → ระบบส่งรหัส 6 หลักทางอีเมล (ใช้ได้ 10 นาที, ใช้ครั้งเดียว, ผิดได้ 5 ครั้ง, ขอรหัสได้ 3 ครั้ง/15 นาที) ทุกครั้งที่เข้าระบบ
- อัปเกรดจากเวอร์ชันรหัสผ่าน: วางทับไฟล์ → **รัน setup() อีกครั้ง** ชีตผู้ใช้เดิมจะถูกเปลี่ยนชื่อเป็น "ผู้ใช้_เดิม_ไม่ใช้แล้ว" และตั้งบัญชีที่รัน setup เป็นผู้ดูแลหลัก → เข้าระบบแล้วเพิ่มผู้ใช้คนอื่นใหม่ด้วยอีเมล
- แท็บ 🔐 ผู้ใช้ระบบ (ผู้ดูแลหลักเท่านั้น): เพิ่มด้วยอีเมล + เลือกสิทธิ์ ระบบส่งอีเมลแจ้งพร้อมลิงก์ให้อัตโนมัติ · ปิดใช้งานได้ทันที
- แท็บ 🛡️ บันทึกการเข้าใช้ (ผู้ดูแลหลักเท่านั้น): ขอ OTP / เข้าสำเร็จ / รหัสผิด / อีเมลที่ไม่มีสิทธิ์พยายามเข้า / ออกจากระบบ / อุปกรณ์-เบราว์เซอร์ · ส่งออก CSV
- ⚠️ ข้อมูลทั้งหมดอยู่ใน Google Sheet: อย่าแชร์ไฟล์ Sheet ให้ผู้อื่นแก้ไข (ให้ใช้งานผ่านเว็บแอปเท่านั้น) เพื่อไม่ให้แก้ชีต "ผู้ใช้" หรือ "บันทึกการเข้าใช้" ได้โดยตรง

## นำเข้า / ส่งออก
- แท็บ ⇅ นำเข้า/ส่งออก: เลือกชุดข้อมูล 10 แบบ → เลือก Excel / CSV / PDF → เลือกคอลัมน์ → ดาวน์โหลด
  (รายชื่อทั้งหมด, ตามตัวกรอง, สรุปจำนวน, กลุ่มเสี่ยง, ผลการเรียนรายภาค, สรุปตรวจสอบจบ, รายวิชา, อาจารย์ที่ปรึกษา, ประวัติส่งรายงาน, บันทึกการแก้ไข)
- ปุ่ม ⬇️ ส่งออก ในแท็บ นักศึกษา / กลุ่มเสี่ยง / รายงานสิ้นภาค / บันทึก ใช้หน้าต่างเดียวกัน · ปุ่ม 📕 PDF ในโปรไฟล์นักศึกษา
- หน้า Dashboard: ส่งออกตารางสรุป (Excel/CSV/PDF) และ 📕 PDF ทั้งหน้า Dashboard (ไม่มีข้อมูลรายบุคคล)
- PDF: A4 หัวกระดาษโลโก้คณะ เลขหน้า วันที่ แบ่งหน้าอัตโนมัติ (สูงสุด 3,000 แถว/ไฟล์)
- นำเข้า: นักศึกษา (มีแม่แบบ), ผลการเรียน, อีเมลอาจารย์ที่ปรึกษา (แม่แบบพร้อมรายชื่ออาจารย์ปัจจุบัน), ไฟล์ตรวจสอบจบ PDF
- ทุกการส่งออกข้อมูลจากชีตถูกบันทึกในบันทึกการแก้ไข

## 📝 บันทึกเพิ่มเติมรายนักศึกษา
- ในโปรไฟล์นักศึกษา (แท็บ ค้นหารายบุคคล): เพิ่มบันทึกได้ไม่จำกัด เลือกหมวด (ทั่วไป/การเรียน/ให้คำปรึกษา/ติดต่อผู้ปกครอง/เอกสาร-คำร้อง/ทุน/กิจกรรม/อื่นๆ)
- 📅 วันนัดติดตาม → แสดงในกล่อง "⏰ ต้องติดตาม" ใต้รายการค้นหา (เลยกำหนด = สีแดง) · กด "✔ ติดตามแล้ว" เพื่อปิด
- 📌 ปักหมุด (ขึ้นบนสุด) · 🔒 ส่วนตัว (เห็นเฉพาะผู้บันทึก + ผู้ดูแลระบบ)
- ทุกสิทธิ์บันทึกได้ (รวม viewer เช่น อาจารย์ที่ปรึกษา) · แก้ไข/ลบได้เฉพาะของตัวเอง (ผู้ดูแลแก้ได้ทุกบันทึก)
- รายชื่อในผลค้นหาแสดงป้าย 📝จำนวนบันทึก · ส่งออกได้ที่ นำเข้า/ส่งออก → บันทึกเพิ่มเติมรายนักศึกษา
- ต้องรัน setup() อีกครั้งเพื่อสร้างชีต "บันทึกนักศึกษา"

## ✅ ตรวจสิทธิ์ / สถานภาพ (แท็บใหม่)
ใช้ข้อมูลจากไฟล์ตรวจสอบจบ (REG) ที่นำเข้าล่าสุด · ต้องรัน setup() อีกครั้ง (สร้างชีต "แผนการศึกษา")
1. **📘 แผนการศึกษา (ตั้งครั้งแรก)**: ใส่รหัสนักศึกษาต้นแบบที่เรียนตามแผน → "สร้างแผน" ระบบดึงรายวิชาแยกชั้นปีจากไฟล์ตรวจสอบจบ (ไม่รวมวิชาเลือกเสรี) ทำแยกแต่ละรหัสหลักสูตร → ดาวน์โหลด Excel ตรวจทาน เพิ่ม "รหัสวิชาทดแทน" (ถ้ามี) → นำเข้ากลับ
2. **🏥 ฝึกงานปี 4**: ลงทะเบียนครบตามแผนปี 1–4 · ติด F ได้ (แสดงเป็นหมายเหตุ)
3. **🏥 ฝึกงานปี 6**: ลงทะเบียนครบตามแผนปี 1–5 + มีผลการเรียนทุกวิชา (ไม่มีรอเกรด) + ไม่มี F ค้าง · เลือกตรวจชั้นปี 5 หรือ 6 ได้
4. **🎓 สำเร็จการศึกษา**: ผลตรวจ REG (ขาด 0 หน่วยกิต, ทุกหมวด PASS, ไม่มีรอเกรด) + GPAX ≥ 2.00 · ผลภาษาอังกฤษเป็นหมายเหตุ
5. **⏳ ตกค้าง**: ชั้นปี 6 ขึ้นไปที่ยังไม่ผ่านเกณฑ์จบ พร้อมจำนวนปีที่ศึกษา
6. **⚖️ สถานภาพ**: รอพินิจ / เข้าเกณฑ์พ้นสภาพ คำนวณจาก GPAX ภาคปกติ (ค่าเริ่มต้น: < 1.50 พ้นสภาพ, 1.50–1.99 รอพินิจ, เริ่มภาคที่ 2, รอพินิจติด 2 ภาค = พ้นสภาพ) → **ปรับให้ตรงระเบียบ มข. ที่ "⚙️ ปรับเกณฑ์"** · สถานภาพแสดงในอีเมลรายงานสิ้นภาคด้วย
- ทุกหน้าส่งออก Excel/CSV/PDF ได้ · กด "ดู" เพื่อเปิดโปรไฟล์นักศึกษา
- ⚠️ ผลเป็นการคัดกรองเบื้องต้นเพื่อลดงาน — ผลทางการยึดตาม REG/ประกาศมหาวิทยาลัย

## อัปเดต: สุขภาพจิตนักศึกษา (ข้อมูลจากฝ่ายพัฒนานักศึกษา)

### ที่ผู้ใช้เห็น
- **โปรไฟล์นักศึกษา** (ค้นหารายบุคคล) ส่วน "สุขภาพจิต" แสดงหัวใจขนาดใหญ่พร้อม "ระดับความสุข" เป็น % ตามสี เป็นหัวใจที่เติมสีตามร้อยละ (100% = เต็มดวง) มีคลื่นของเหลว เต้นเป็นจังหวะ และเรืองแสงฟุ้ง
  - สีตามระดับ: ≥80 ดีมาก (ชมพูแดง) · 60–79 ดี (ชมพู) · 40–59 ควรติดตาม (ส้ม) · <40 ควรได้รับการดูแล (ม่วง เต้นช้าลง)
  - ระดับการเติมคิดตาม "พื้นที่" ของหัวใจ จึงดูสัดส่วนได้ถูกต้อง
  - มีลูกศร ▲▼ เทียบกับครั้งก่อน
  - กดที่หัวใจหรือปุ่ม "แสดงประวัติการประเมิน" เพื่อดูไทม์ไลน์ผลประเมินทุกครั้ง (การกดดูถูกบันทึก)
- **เมนูใหม่ "สุขภาพจิตนักศึกษา"**
  - สรุปจำนวนตามระดับ
  - รายชื่อที่ต่ำกว่า 60% เรียงจากน้อยไปมาก กดเปิดโปรไฟล์ได้
  - นำเข้าข้อมูล, ประวัติการนำเข้า + ปุ่มย้อนการนำเข้า
  - ตั้งค่าสิทธิ์

### การรับข้อมูลจากฝ่ายพัฒนานักศึกษา (2 ทาง)
1. **อัปโหลดไฟล์ Excel/CSV**
   - มีปุ่มดาวน์โหลดแม่แบบ
   - ไฟล์ต้นฉบับถูกเก็บใน Drive: `ข้อมูลสุขภาพจิต (ฝ่ายพัฒนานักศึกษา)/ปี/ภาค n`
2. **เชื่อมโยง Google Sheet ของฝ่ายพัฒนานักศึกษา**
   - ผู้ดูแลใส่ลิงก์ในการ์ด "สิทธิ์และการเชื่อมโยงข้อมูล"
   - ฝ่ายพัฒนานักศึกษาแชร์ชีตให้บัญชีเจ้าของระบบ (ผู้ Deploy) แบบ **ผู้มีสิทธิ์อ่าน**
   - เมื่อกด "ดึงข้อมูลล่าสุด" ระบบอ่านชีตนั้นมาให้จับคู่คอลัมน์
   - เลือกแท็บได้ถ้ามีหลายแท็บ

ทั้งสองทางผ่านขั้นตอนเดียวกัน:
- **จับคู่คอลัมน์อัตโนมัติ** (แก้เองได้): รหัสนักศึกษา, ร้อยละ หรือ คะแนน + คะแนนเต็ม, วันที่ประเมิน, แบบประเมิน, หมายเหตุ
- ติ๊ก **"คะแนนสูง = สุขภาพจิตแย่"** สำหรับแบบวัดความเครียด/ซึมเศร้า (เช่น ST-5, PHQ-9) ระบบจะกลับด้านเป็น 100 − ร้อยละ
- **ดูตัวอย่าง** พร้อมหัวใจ และตรวจรหัสไม่ถูกต้อง/ไม่พบในระบบ/คะแนนไม่ครบ ก่อนนำเข้า
- รหัสแบบไม่มีขีด (10 หลัก) แปลงให้อัตโนมัติ
- ข้อมูลซ้ำ (รหัส + วันที่ + แบบประเมินเดียวกัน) จะถูกข้าม

### ความปลอดภัย (ข้อมูลอ่อนไหว)
- เห็นได้เฉพาะ **owner/admin** และอีเมลที่ระบุใน "อีเมลผู้มีสิทธิ์ข้อมูลสุขภาพจิต"
  - เจ้าหน้าที่ฝ่ายพัฒนานักศึกษาต้องมีบัญชีในเมนู "ผู้ใช้ระบบ" ด้วย
  - ผู้ใช้อื่น (staff/viewer) จะไม่ได้รับข้อมูลนี้จากเซิร์ฟเวอร์เลย
- **ไม่แสดงบน Dashboard สาธารณะ** และไม่อยู่ในไฟล์ส่งออกรายชื่อนักศึกษา
- เก็บในชีต `สุขภาพจิต` ซึ่งถูก **ซ่อน** อัตโนมัติ
- การดูภาพรวม, ดูประวัติรายคน, นำเข้า, ย้อน และตั้งค่า ถูกบันทึกในบันทึกการแก้ไขทุกครั้ง
- ร้อยละเป็นข้อมูลประกอบการดูแลเท่านั้น ไม่ใช่การวินิจฉัย

### เพิ่มเติม: รายด้าน ซึมเศร้า / เครียด / กดดัน + สถานะความเสี่ยง
- ชีต `สุขภาพจิต` มีคอลัมน์ใหม่ (ระบบเพิ่มให้อัตโนมัติเมื่อนำเข้าครั้งแรก):

  - ไฟล์ใส่เป็นข้อความระดับ (ไทย/อังกฤษ เช่น Normal/Mild/Moderate/Severe/Extremely severe) หรือตัวเลขก็ได้
  - ถ้าเป็นคะแนนดิบ ให้กรอก "คะแนนเต็มรายด้าน"
  - ร้อยละรายด้านแปลงเป็นระดับ: <20 ปกติ · <40 เล็กน้อย · <60 ปานกลาง · <80 รุนแรง · ≥80 รุนแรงมาก
- **สุขภาพจิตรวม (หัวใจ):** ถ้าไฟล์ไม่มี ระบบคำนวณจากรายด้าน = 100 − ค่าเฉลี่ยความรุนแรง
- **สถานะความเสี่ยง:** ปกติ · เฝ้าระวัง · เสี่ยง · เสี่ยงสูง
  - คำนวณจาก: มีด้านใดรุนแรงขึ้นไป หรือสุขภาพจิตรวม <40% → เสี่ยงสูง · ปานกลาง หรือ <60% → เสี่ยง · เล็กน้อย → เฝ้าระวัง
  - ถ้าฝ่ายพัฒนานักศึกษาระบุสถานะมาในไฟล์ ระบบใช้ **ระดับที่สูงกว่า** ระหว่างที่ระบุกับที่คำนวณ เพื่อไม่ให้กลุ่มเสี่ยงหลุด
- **การแสดงผล:**
  - หัวโปรไฟล์: ป้ายสถานะความเสี่ยง (เสี่ยงสูงมีจุดกระพริบ)
  - ส่วนสุขภาพจิตในโปรไฟล์: แถบ 3 ด้านพร้อมระดับ และบอกว่าสถานะเพิ่มขึ้น/ลดลงจากครั้งก่อน
  - หน้า "สุขภาพจิตนักศึกษา": การ์ดนับตามสถานะ (กดเพื่อกรองรายชื่อ) และรายชื่อเรียงจากเสี่ยงสูงสุด

## อัปเดต: ตรวจสิทธิ์ฝึกงานปี 4 / ปี 6 / สำเร็จการศึกษา — ตั้งค่าเกณฑ์ได้ + ตรวจทานด้วยช่องติ๊ก

### ตรวจอัตโนมัติจากไฟล์ใบตรวจสอบจบ (REG)
- ระบบอ่านไฟล์ PDF ตรวจสอบจบที่อัปโหลดในเมนู "ไฟล์ตรวจสอบจบ" และแผนการศึกษา แล้วตรวจทุกคนตามเกณฑ์ที่ตั้งไว้
- กด **"รีเช็คจากไฟล์ REG"** เพื่อตรวจใหม่หลังอัปโหลดไฟล์ล่าสุด

### ตั้งค่าเกณฑ์ (ผู้ดูแลระบบ · ปุ่ม "ตั้งค่าเกณฑ์" ในแต่ละแท็บ)
ทุกข้อเลือกได้ว่า **ใช้/ไม่ใช้**, **ค่ากำหนด** และ **ถ้าไม่ตรงเกณฑ์ → ไม่ผ่าน หรือแสดงเป็นหมายเหตุ**

| เกณฑ์ | ฝึกงานปี 4 (ค่าเริ่มต้น) | ฝึกงานปี 6 | สำเร็จการศึกษา / ตกค้าง |

- ตั้ง **ชั้นปีที่ตรวจ** ได้ · แท็บตกค้างตั้ง "ชั้นปีตั้งแต่" และ "ศึกษามาเกิน (ปี)" ได้

### ตรวจทานด้วยช่องติ๊ก
- กดปุ่ม **รายการตรวจ** (จุดสีเขียว/แดง/เหลือง) เพื่อเปิดเช็กลิสต์รายข้อ
  - แต่ละข้อแสดงรายละเอียดจากไฟล์ REG และ "ระบบตรวจ: ผ่าน/ไม่ผ่าน"
- **ติ๊ก/เอาติ๊กออกเพื่อแก้ผลรายข้อ** (เช่น ยืนยันกับงานทะเบียนแล้ว)
  - ข้อที่แก้มีกรอบเส้นประสีน้ำเงิน และผลรวมคำนวณใหม่ทันที
  - แสดง "ระบบ: ไม่ผ่าน → แก้โดยเจ้าหน้าที่" · มีช่องหมายเหตุ และปุ่มคืนค่าตามผลระบบ
- ช่อง **ตรวจทาน** หน้าชื่อ = ติ๊กเมื่อเจ้าหน้าที่ตรวจทานคนนั้นแล้ว (บันทึกชื่อผู้ตรวจและเวลา)
- มีปุ่ม "ติ๊กตรวจทานคนที่แสดง" สำหรับติ๊กทีละหลายคน
- ตัวกรอง: ยังไม่ตรวจทาน · แก้ผลโดยเจ้าหน้าที่ · **มีไฟล์ REG ใหม่หลังตรวจทาน** (ควรตรวจทานใหม่)
- ผลตรวจทานเก็บในชีต `ผลตรวจทานสิทธิ์` แยกตามรอบ (โหมด + ชั้นปี + ปีการศึกษา) จึงไม่ปนข้ามปี
- ไฟล์ส่งออกมีคอลัมน์ ผล (หลังตรวจทาน), ผลตรวจระบบ, ตรวจทานแล้ว, ผู้ตรวจทาน, หมายเหตุการตรวจทาน

ฟังก์ชันใหม่: `adminEligSaveCfg`, `adminEligResetCfg`, `adminEligSaveReview` (+ `adminEligibility` คืน `checks`, `cfg`, `round`, `rev`)

## อัปเดต: "ข้อมูล ณ ภาค" = ภาคการศึกษาปัจจุบันที่ผู้ดูแลกำหนด (ไม่นับจากภาคของเกรด)

## อัปเดต: ตรวจสอบการออกฝึกงาน ปี 4 / ปี 6 / สำเร็จการศึกษา — เงื่อนไขแบบสวิตช์ + แดชบอร์ดสรุป

### เงื่อนไข (สวิตช์เปิด/ปิด · เพิ่ม/ลบได้อิสระ)
- **การ์ดเงื่อนไข:** แต่ละใบมีสวิตช์เลื่อนเปิด/ปิด
  - เลื่อนสวิตช์ในมุมมองย่อ = บันทึกและตรวจใหม่ทันที (ผู้ดูแลระบบ)
- **ปุ่ม "กำหนดเงื่อนไข"** เปิดโหมดแก้ไข:
  - ติ๊กชั้นปีของแผนการศึกษา (ปี 1–6)
  - ใส่จำนวน F/I ที่ยอมให้ค้าง, GPAX, หน่วยกิต, รหัสวิชา
  - เลือก "ต้องผ่าน" หรือ "แจ้งเตือน"
  - ปุ่ม − ลบเงื่อนไข · "+ เพิ่มเงื่อนไข…"
- **ประเภทเงื่อนไข:**
  - ลงทะเบียนครบตามแผน (เลือกชั้นปี)
  - สอบผ่านรายวิชาบังคับตามแผน (เลือกชั้นปี)
  - ไม่ติด F/U ค้าง · ไม่ติด I ค้าง (กำหนดจำนวนที่ยอมได้)
  - ไม่มีรอเกรด
  - รายวิชาที่กำหนดต้องผ่าน
  - GPAX ขั้นต่ำ · หน่วยกิตผ่านขั้นต่ำ
  - หน่วยกิตขาด = 0 (REG) · ทุกหมวด PASS (REG)
  - ภาษาอังกฤษ PASS
  - อายุไฟล์ REG
- เงื่อนไขรูปแบบเดิมที่เคยตั้งไว้ถูกแปลงให้อัตโนมัติ

### แดชบอร์ดสรุป (กดทุกกราฟเพื่อกรองรายชื่อ)
- **ตัวเลขรวม:** ทั้งหมด · ครบ/พร้อม (%) · ไม่ครบ (%) · ไม่มีไฟล์ REG · ติด F ค้าง (คน/วิชา) · ตรวจทานแล้ว (แถบความคืบหน้า)
- **ไม่ผ่านเพราะอะไร:** จำนวนคนที่ไม่ผ่านแต่ละเงื่อนไข
- **รายวิชา F:** ค้าง / แก้แล้ว / I ค้าง และวิชาที่มีคนติด F ค้างมากที่สุด (กดชื่อวิชาเพื่อดูรายชื่อ)
- **ความครบตามแผนรายชั้นปี:** แถบสี ครบ/รอเกรด-ติด I/ขาด-ติด F

### รายบุคคล
- **ไทม์ไลน์แผนการศึกษา** ปี 1–6 เป็นสี
  - เขียว = ครบ · เหลือง = รอเกรด/ติด I · แดง = ขาดหรือติด F · เทา = ยังไม่ถึงชั้นปีนั้น
- คอลัมน์ **รายวิชา F:** "F ค้าง n" / "I n" / "แก้แล้ว n"
- กดไทม์ไลน์เพื่อเปิดรายละเอียด:
  - เช็กลิสต์เงื่อนไข (ติ๊กแก้ผลรายข้อได้)
  - ตารางวิชา F/U/I พร้อมประวัติเกรด เช่น F (1/2566) → A (1/2567) และสถานะแก้แล้ว/ยังไม่แก้
  - รายการวิชาที่ยังไม่ลงทะเบียนตามแผน แยกชั้นปี

### ส่งออก (ปุ่ม "ส่งออก ▾") — ตามตัวกรองที่แสดงอยู่ · Excel / PDF
1. รายชื่อผลตรวจ (รวมคอลัมน์ F ค้าง / F แก้แล้ว / แผนปีที่ยังไม่ครบ / ผลตรวจทาน)
2. รายวิชา F / I รายคน (ประวัติเกรด · แก้แล้ว/ยังไม่แก้)
3. วิชาที่ยังไม่ลงทะเบียนตามแผน
4. สรุปภาพรวม (จำนวนตามเงื่อนไข · วิชาที่ติด F มากที่สุด · แผนรายชั้นปี)

## อัปเดต: ใบแจ้งผล PDF · บันทึกผลเป็นรอบ · แจ้งเตือนอัตโนมัติ · ธีมเขียวเอิร์ธโทน

### 1) ใบแจ้งผลตรวจรายบุคคล (PDF · 1 คน 1 หน้า A4)
- **ออกทีละคน:** ปุ่ม "ใบแจ้งผล PDF" ในรายละเอียดรายคน
- **ออกหลายคน:** "ส่งออก ▾ → ใบแจ้งผลรายบุคคล (PDF)" ออกตามตัวกรองที่แสดงอยู่ รวมเป็นไฟล์เดียว
- **เนื้อหา:**
  - ข้อมูลนักศึกษาและผลรวม (ครบ/ยังไม่ครบ)
  - ไทม์ไลน์แผนการศึกษาเป็นสี
  - ตารางผลตามเงื่อนไข · รายวิชา F/U/I (ประวัติเกรด แก้แล้ว/ยังไม่แก้) · วิชาที่ยังไม่ลงทะเบียน · หมายเหตุ
  - ช่องลงชื่อ 3 ช่อง: นักศึกษา · อาจารย์ที่ปรึกษา · เจ้าหน้าที่งานบริการการศึกษา

### 2) บันทึกผลเป็นรอบ + เทียบการเปลี่ยนแปลง
- **ปุ่ม "บันทึกผลรอบนี้"** ตั้งชื่อรอบได้ ผลเก็บในชีต `รอบผลตรวจสิทธิ์` (ซ่อนไว้)
- **แถบ "เทียบกับรอบ"** เปิดมาเทียบกับรอบล่าสุดอัตโนมัติ:
  - สรุป ▲ เพิ่งครบ · ▼ กลับเป็นไม่ครบ · แก้ F/I แล้ว · F/I ใหม่ (กดเพื่อกรอง)
  - แต่ละคนมีป้ายบอกการเปลี่ยนแปลงใต้ผล
- ผู้ดูแลลบรอบได้

### 3) แจ้งเตือนอัตโนมัติหลังอัปโหลดไฟล์ REG
- **เมื่อบันทึกไฟล์ตรวจสอบจบเสร็จ** ระบบตรวจทุกหัวข้อ (ฝึกงานปี 4 · ปี 6 · สำเร็จการศึกษา) ใหม่ แล้วเทียบกับผลครั้งก่อน
  - ผลครั้งก่อนคือรอบ "อัตโนมัติ" ซึ่งระบบเก็บไว้ให้เองทุกครั้งที่อัปโหลด
  - แสดงป๊อปอัปว่าใครเปลี่ยนจากไม่ครบเป็นครบ (หรือกลับกัน) และใครแก้ F แล้วหรือมี F ใหม่
  - ครั้งแรกระบบจะเริ่มติดตาม ยังไม่มีอะไรให้เทียบ
- **ส่งอีเมลสรุป** ถึงผู้รับที่ตั้งไว้ใน "กำหนดเงื่อนไข" → สวิตช์ "แจ้งเตือนทางอีเมล…" + ช่องอีเมลผู้รับ (ผู้ดูแลระบบ)

- ทั้ง Dashboard / Admin / ป๊อปอัป / ไฟล์ส่งออก / อีเมล ใช้โทน Forest · Moss · Olive บนพื้นสีกระดาษอุ่น รองรับโหมดมืด
- **สีกราฟ:** มอส · ฟ้าหม่น · เขียวหัวเป็ด · ทองมัสตาร์ด · ดินเผา · มะกอก · ม่วงพลัม · อิฐ

## อัปเดต: คัดกรองสุขภาวะจากสถานการณ์ผลการเรียน (ฝ่ายพัฒนานักศึกษาไม่มีเกณฑ์คะแนน)
ระบบประเมินเบื้องต้นเองจาก **ผลการเรียน + การคาดการณ์ + ผลแบบประเมิน (ถ้ามี)** แล้วแจ้งว่า **"ควรเชิญมาทำแบบประเมิน"**
ผลนี้ใช้เพื่อคัดกรอง ไม่ใช่การวินิจฉัย

### สัญญาณที่ใช้ (คะแนนน้ำหนัก)
| สัญญาณ | น้ำหนัก |
|---|---|
| GPAX ต่ำกว่าเกณฑ์ (GPAX_THRESHOLD) | 3 |
| GPAX อยู่ช่วงเฝ้าระวัง (GPAX_WATCH) | 1 |
| สถานภาพเบื้องต้น: เข้าเกณฑ์พ้นสภาพ / รอพินิจ | 3 / 2 |
| GPA ภาคล่าสุดลดลง ≥ 0.50 / ≥ 0.30 | 2 / 1 |
| GPA ลดลงต่อเนื่อง 3 ภาค | 1 |
| GPA ภาคล่าสุด < 1.50 | 2 |
| **คาดการณ์:** GPAX ภาคหน้าอาจต่ำกว่าเกณฑ์ / ลดลงเข้าช่วงเฝ้าระวัง | 2 / 1 |
| ติด F/U ค้าง ≥ 2 / 1 วิชา | 2 / 1 |
| เคยติด F รวม ≥ 3 ครั้ง | 1 |
| ศึกษาเกิน 6 ปี (ตกค้าง) | 2 |
| ผลแบบประเมินฝ่ายพัฒนาฯ (ถ้ามีสถานะ): เสี่ยงสูง / เสี่ยง / เฝ้าระวัง | 4 / 2 / 1 |

- **การคาดการณ์:** คาด GPA ภาคหน้าจากแนวโน้ม GPA 3 ภาคล่าสุด แล้วเฉลี่ยเข้ากับ GPAX สะสม
- **ระดับ:** รวม ≥ 4 = **ควรเชิญทำแบบประเมิน** · 2–3 = เฝ้าระวัง · 0–1 = ปกติ
- **ดัชนีสุขภาวะเบื้องต้น (หัวใจ %):** ใช้ร้อยละจากแบบประเมินถ้ามี ถ้าไม่มีใช้ 100 − คะแนนสัญญาณ × 11 และระบุแหล่งที่มาทุกครั้ง

### การใช้งาน
- **โปรไฟล์นักศึกษา → "สุขภาวะ / สุขภาพจิต":**
  - หัวใจ % · ระดับ · สัญญาณที่พบ · ค่าคาดการณ์ GPAX ภาคหน้า
  - ถ้าควรเชิญจะมีกล่องเตือน "ดูจากสถานการณ์ผลการเรียนแล้ว ควรเชิญนักศึกษามาทำแบบประเมินสุขภาวะ"
  - ปุ่มสถานะการดูแล: ควรเชิญ → เชิญแล้ว → ทำแบบประเมินแล้ว → ติดตามต่อ / ปิดเรื่อง
- **เมนู "สุขภาพจิตนักศึกษา" → การ์ด "คัดกรองสุขภาวะจากสถานการณ์ผลการเรียน":**
  - นับจำนวน ควรเชิญ / เฝ้าระวัง / ยังไม่ได้เชิญ / เชิญแล้ว / ทำแบบประเมินแล้ว (กดเพื่อกรอง)
  - ตารางรายชื่อพร้อมสัญญาณ · ติ๊กหลายคนแล้วบันทึกสถานะพร้อมกัน
  - **ส่งออกรายชื่อ** เพื่อส่งให้ฝ่ายพัฒนานักศึกษา / อาจารย์ที่ปรึกษา
- **นำเข้าผลแบบประเมิน:** ไม่บังคับคะแนนแล้ว
  - ไฟล์มีแค่รหัสนักศึกษา + วันที่ = บันทึกว่า "ทำแบบประเมินแล้ว"
  - ระบบอัปเดตสถานะการดูแลให้อัตโนมัติ
- สถานะการดูแลเก็บในชีต `การดูแลสุขภาวะ` (ซ่อน) · เห็นเฉพาะผู้มีสิทธิ์ข้อมูลสุขภาพจิต · บันทึกทุกการเข้าดู
- ฟังก์ชันใหม่: `adminWBList`, `adminWBCareSet` (+ `_wb` ใน bootstrap สำหรับผู้มีสิทธิ์)

## อัปเดต: หน้าเข้าสู่ระบบ ไอคอน และ pop-up แจ้งเตือน

- **ผู้ดูแลระบบ:** กด "ดูในมุมอาจารย์" เพื่อตรวจสิ่งที่อาจารย์แต่ละท่านจะเห็นได้

  - ใช้ได้จากหน้ากลุ่มเสี่ยง หน้าตรวจสิทธิ์ และหน้า "งานของฉันวันนี้"
  - ระบบจัดกลุ่มตามอาจารย์ ส่งอีเมลคนละฉบับ และแสดงให้ดูก่อนส่งว่าอาจารย์ท่านใดยังไม่มีอีเมล
### 2) ศูนย์แจ้งเตือน (กระดิ่งมุมบน)
- `adminNotices` ตรวจเรื่องต่อไปนี้:
  - นัดติดตามถึงกำหนด
  - ข้อมูลรออนุมัติ
  - ยังไม่อัปเดตข้อมูลนักศึกษา/ผลการเรียนของภาคปัจจุบัน
  - GPAX ต่ำกว่า 1.75 / ต่ำกว่าเกณฑ์ และ F ค้าง
  - ควรเชิญทำแบบประเมิน (เฉพาะผู้มีสิทธิ์)
  - อาจารย์ที่ยังไม่มีอีเมล
  - ยังไม่ตั้งสำรองข้อมูล
- ตรวจใหม่ทุก 10 นาที
- กดแต่ละรายการแล้วไปยังหน้านั้นทันที และจำสถานะ "อ่านแล้ว" แยกตามผู้ใช้
### 3) หน้า "งานของฉันวันนี้"
- เป็นหน้าแรกหลังเข้าระบบ ประกอบด้วย:
  - คำทักทายและวันที่
  - ตัวเลขสรุป (กดแล้วไปหน้านั้น)
  - รายการงานที่ควรทำ พร้อมปุ่ม "ไปที่งาน" และปุ่มส่งรายชื่อให้อาจารย์
  - นัดติดตามของฉัน
  - ทางลัด
  - การ์ดพอร์ทัลอาจารย์ (ผู้ดูแลระบบ)

## อัปเดต: เกณฑ์ผลการเรียนและสถานภาพแบบรวมศูนย์ + ข้อมูลนักศึกษารายภาค
### ตั้งค่าเกณฑ์ (ปุ่ม "ตั้งค่าเกณฑ์")
- **ที่อยู่ของปุ่ม:** หน้ากลุ่มเสี่ยง, ตรวจสิทธิ์ → สถานภาพ, คัดกรองสุขภาวะ, ตั้งค่า
- **สิทธิ์:** ผู้ดูแลระบบแก้ไขได้ ผู้ใช้อื่นดูได้อย่างเดียว
- **ระดับผลการเรียน (GPAX):** 1–6 ระดับ ตั้งชื่อ สี และค่า "ต่ำกว่า" ได้เอง
  - ใช้กับ: กลุ่มเสี่ยง, รายงาน, คัดกรองสุขภาวะ, พอร์ทัลอาจารย์, ศูนย์แจ้งเตือน, ชีตผู้บริหาร, ชีตร่วมฝ่ายพัฒนาฯ
- **เกณฑ์สถานภาพ:** เพิ่ม/ลบ/เปิด-ปิดได้ไม่เกิน 12 ข้อ
  - ประเภทที่เลือกได้:
    - พ้นสภาพเมื่อ GPAX < x
    - พ้นสภาพเมื่อ GPAX < x ติดต่อกัน n ภาค
    - พ้นสภาพเมื่อศึกษาเกิน n ปี
    - รอพินิจเมื่อ GPAX < x
    - รอพินิจเมื่อ GPA ภาค < x
  - ทุกข้อกำหนด "เริ่มนับตั้งแต่ภาคปกติที่" ได้
- **GPAX สำเร็จการศึกษาขั้นต่ำ** ตั้งค่าได้ในหน้าต่างเดียวกัน
- **ช่องทดลอง:** พิมพ์ GPAX รายภาค แล้วดูผลทันทีว่าเป็นปกติ / รอพินิจ / พ้นสภาพ
- **ผลกระทบ:** คำนวณให้ดูก่อนบันทึก (ปัจจุบัน → เกณฑ์ใหม่ พร้อมส่วนต่าง)
- **"ตกออก/พ้นสภาพ" ใช้นิยามเดียวทั้งระบบ:** คือผลจากเกณฑ์สถานภาพ ระดับ GPAX ไม่ได้หมายถึงตกออกอีกต่อไป
- **การเก็บค่า:** เก็บใน `ACAD_RULES` (JSON) และซิงก์ค่าเดิมให้อัตโนมัติ (`GPAX_THRESHOLD`, `GPAX_WATCH`, `WB_BAND1-3`, `PROB_*`, `GRAD_GPAX`)
### ข้อมูลนักศึกษารายภาค (ชีตซ่อน `ข้อมูลนักศึกษารายภาค`)
- **ข้อมูลที่เก็บ:** ชั้นปี / สถานะ / หลักสูตร / อาจารย์ที่ปรึกษา ณ แต่ละภาค
- **เก็บอัตโนมัติเมื่อ:** นำเข้าข้อมูลนักศึกษาโดยระบุภาค, ตั้งภาคปัจจุบัน, หรือปิดภาค
- **เก็บด้วยตนเอง:** กดปุ่มที่หน้าปิดภาคการศึกษา
- **ดูย้อนหลัง:** เลือก "ข้อมูล ณ ภาค" ย้อนหลัง หน้ากลุ่มเสี่ยงจะใช้สถานะ/ชั้นปีของภาคนั้น
- **เปรียบเทียบ 2 ภาค:** ดูได้ว่าใครเปลี่ยนสถานะ (เช่น กำลังศึกษา → พ้นสภาพ), ใครเข้าใหม่, ใครไม่อยู่ในภาคหลัง, ใครเลื่อนชั้นปี, ใครเปลี่ยนอาจารย์ และส่งออกผลได้
- **ไทม์ไลน์นักศึกษา:** แสดงการเปลี่ยนสถานะ/ชั้นปีรายภาคจากข้อมูลนี้

## อัปเดต: ปุ่มย้อนกลับ / รีเฟรช / อนุมัติทั้งหมด

  - บันทึกในประวัติการแก้ไข

## อัปเดต: จุดเชื่อมต่อฝ่ายพัฒนานักศึกษา — เลือกหัวข้อข้อมูลและเงื่อนไขได้เอง

- **สวิตช์รายหัวข้อ 27 หัวข้อ** แบ่ง 5 กลุ่ม แต่ละกลุ่มมีปุ่มเปิด/ปิดทั้งหมด
  - ข้อมูลพื้นฐาน · การคัดกรอง · ผลการเรียน · ข้อมูลติดต่อ · ข้อมูลส่วนตัว
  - รหัสนักศึกษาเปิดเสมอ เพราะใช้จับคู่ผลการติดตามที่ฝ่ายพัฒนาฯ กรอกกลับ
  - ข้อมูลติดต่อ/ส่วนตัวต้องกดยืนยันก่อนเปิด และบันทึกในประวัติการเข้าใช้

  - เลือกได้ว่าต้องตรง "ข้อใดข้อหนึ่ง" หรือ "ทุกข้อ"
  - ประเภทเงื่อนไข:

    - ระดับ GPAX ตั้งแต่
    - GPAX ต่ำกว่า
    - สถานภาพ (รอพินิจ/พ้นสภาพ)
    - F/U ค้างอย่างน้อย
    - GPA ภาคล่าสุดลดลงอย่างน้อย
    - ชั้นปี
    - สถานะการดูแล
  - สวิตช์ "ส่งต่อคนที่ยังอยู่ระหว่างการดูแลเสมอ"

- **เก็บค่าที่** `MH_OUT_CFG` (แทน `MH_LINK_SCOPE` / `MH_LINK_GPAX` เดิม ซึ่งยกค่ามาเป็นค่าเริ่มต้นให้แล้ว)
- **ไม่ส่งเลยในทุกกรณี:** ผลแบบประเมินสุขภาพจิต, บันทึกอาจารย์, คะแนนดัชนี/กราฟใยแมงมุม, ข้อมูลผู้ปกครอง

  - การแจ้งเตือนแคชรายผู้ใช้ 10 นาที (ปุ่ม "ตรวจใหม่" บังคับคำนวณใหม่)

- **การแจ้งเตือนโหลดหลังหน้าแอปแสดงแล้ว** (ไม่บล็อกการเปิดระบบ)

  - แถบเมนูล่างไม่ขึ้นที่หน้าเข้าสู่ระบบแล้ว
  - การ์ดตัวเลข (เช่น หน้าตรวจสิทธิ์) แสดง 2 คอลัมน์ ไม่บีบเป็นตัวหนังสือแนวตั้ง

## ตรวจสิทธิ์ฝึกงาน / จบ — โหมดตรวจง่าย (v. ล่าสุด)

- การ์ดใหม่ "รายชื่อ + GPAX ล่าสุด": กรองกลุ่ม (ภาคปกติ/โครงการพิเศษ/นานาชาติ) · ชั้นปี · สถานะ · แยกชีตตามชั้นปี/กลุ่ม/กลุ่ม×ชั้นปี · มีกราฟ GPAX เฉลี่ย และจำนวนตามระดับผลการเรียน

## แก้: ดาวน์โหลด Excel/PDF ไม่ได้ในหน้าเว็บจริง
- สาเหตุ: หน้าเว็บ Apps Script อนุญาตให้ดาวน์โหลดอัตโนมัติได้เพียงไม่กี่วินาทีหลังคลิก ถ้าสร้างไฟล์นาน (โหลดตัวสร้าง Excel/กราฟ) เบราว์เซอร์จะบล็อกเงียบ ๆ
- แก้: `save()` ดาวน์โหลดทันทีถ้ายังอยู่ในช่วงคลิก ไม่เช่นนั้นแสดงแถบ "ไฟล์พร้อมแล้ว · ดาวน์โหลดไฟล์" ให้กด · โหลดตัวสร้าง Excel ล่วงหน้าตั้งแต่เปิดหน้าต่างส่งออก · ใช้กับ Excel/PDF ทุกจุด (รวมแม่แบบ และ PDF โปรไฟล์)

## ล้างข้อมูลผลการเรียนที่นำเข้า (ผู้ดูแลหลัก)
- หน้า นำเข้า/ส่งออก → การ์ด "ล้างข้อมูลผลการเรียนที่นำเข้า": เลือก ผลการเรียนรายภาค (GPA/GPAX) รายภาค/ทุกภาค หรือ ใบตรวจสอบจบ (REG) + รายวิชา รายชั้นปี/ทุกชั้นปี → ตรวจจำนวน → พิมพ์ "ล้างข้อมูล" → ล้าง
- สำรองแถวที่ลบเป็น Google Sheet "สำรองก่อนล้าง — …" ในโฟลเดอร์ Drive ทุกครั้ง · บันทึกในบันทึกการแก้ไข · ไฟล์ PDF ใน Drive ไม่ถูกลบ
- API: `adminGradeClearPreview(token, what, o)`, `adminGradeClear(token, what, o, 'ล้างข้อมูล')`

## สร้างเงื่อนไขเอง (ปุ่ม +) · แก้แถบเลขหน้า
- ปุ่ม + ข้าง "เพิ่มเงื่อนไข…": ตั้งชื่อเอง + เลือกแบบตรวจ (รายวิชาต้องผ่าน / ต้องลงทะเบียน / หมวดวิชา REG ผ่านเกณฑ์ / GPAX / หน่วยกิตสะสม / F ค้างไม่เกิน / ตรวจด้วยตนเอง) + ไม่ผ่าน/แจ้งเตือน
- ประเภทใหม่: `mustReg`, `catCredit` (p.q หมวด, p.v หน่วยกิต), `manual` (เจ้าหน้าที่ติ๊กยืนยันรายคน) · รหัสวิชาใช้ `A/B` = รหัสใดรหัสหนึ่ง
- แก้: แถบเลขหน้าใต้ตารางตรวจสิทธิ์ไม่แสดง (ชื่อคลาสชนกับแถบความคืบหน้า) → เปลี่ยนเป็น `.el-pager`

## โปรไฟล์: ดูรายวิชาในแต่ละหมวด (สถานะตามหลักสูตร)
- ทุกหมวดมีปุ่มลูกศร ▾ (กางแล้วหมุนขึ้น) → แสดงรายวิชาในหมวดนั้นใต้แถว (รหัส ชื่อ หน่วยกิต ภาค เกรด) + สรุปจำนวนวิชา หน่วยกิตที่ผ่าน รอเกรด เกณฑ์ของหมวด · จับคู่จากเลขหมวดในไฟล์ REG (หมวดแม่รวมหมวดย่อย)
- แก้ไอคอนหมายเหตุที่ไม่แสดง (info → note)

## แก้: กด PDF / CSV / Excel แล้วไม่มีไฟล์ · ระบบโหลดช้า
- ตัวสร้าง Excel/PDF (xlsx, jszip, jspdf, html2canvas) และ chart.js กลับมาโหลดด้วยแท็ก `<script defer>` (วิธีเดิมที่ใช้ได้บน Apps Script) — defer ไม่บล็อกการเปิดหน้า · ตัวโหลดสำรอง (LIB) ใช้เมื่อแท็กโหลดไม่สำเร็จ
- `save()` สั่งดาวน์โหลดทันทีทุกครั้ง + แถบ "ดาวน์โหลดไฟล์" สำรองที่มุมล่าง
- ปุ่มส่งออกในหน้าตรวจสิทธิ์: ถ้าผิดพลาด แจ้งข้อความ (ไม่เงียบ)
- ผลตรวจสิทธิ์ (adminEligibility) แคชตามเวอร์ชันข้อมูล 1 ชม. — คำนวณใหม่เมื่อมีนำเข้า/แก้ข้อมูล/แก้เงื่อนไข · ผลตรวจทานรายคนอ่านสดทุกครั้ง

## แก้ต้นเหตุ "XP is not defined" (ส่งออกไม่ได้ทั้งระบบ)
- Export.html มีข้อความ XML declaration (`<` + `?xml … ?` + `>`) เขียนตรง ๆ ในโค้ดสร้างกราฟ Excel — Apps Script ตีความเป็นแท็กพิเศษ ทำให้สคริปต์ Export ทั้งไฟล์พัง → ตัวแปร XP ไม่ถูกสร้าง
- แก้: ประกอบข้อความจากชิ้นส่วน (`XMLH`) · ข้อควรระวัง: ห้ามมี `<` ตามด้วย `?` ติดกันในไฟล์ .html ของโปรเจกต์ (ยกเว้นแท็กเทมเพลต)

## ส่งออก Excel ไม่สร้างกราฟแล้ว
- เอาการสร้างชีต "กราฟสรุป" ออกทั้งหมด (โค้ดกราฟ + jszip) — Excel เป็นข้อมูลตารางล้วน (ชีตแยกตามที่เลือกยังมีเหมือนเดิม)
